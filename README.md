# Atelier Minimalist

A minimal website for an interior architecture studio, built around spaces, materials, and visual storytelling.

[Live website](https://atelier-minimalist.vercel.app)

### Highlights
- Project archive and individual project pages
- Studio journal and contact pages
- Simple navigation and subtle transitions

**Stack:** React, TypeScript, Vite, React Router, Framer Motion

### Run locally
```bash
npm ci
npm run dev
```
